# assets

Every image in this repository — the README demo, the icon set, and the GitHub social
preview — was generated by this plugin, through the Codex CLI on a ChatGPT plan. No image
here was made in a chat window, and none was hand-drawn.

The exact commands, in the order they were run:

```bash
STYLE="flat vector icon, single centered glyph, warm off-white #FAF9F5 background, \
terracotta #D97757 fill with a darker #8C4A32 2px outline, no gradients, no shadows, \
no text, generous margins, crisp geometric shapes"

# 1. the base icon — establishes the style
codex-imagegen "A paper rocket ascending at a 45 degree angle with two short motion \
lines behind it. $STYLE" assets/icon-rocket.png --size 1024x1024

# 2. sibling — the base icon is passed as --ref so the style carries over instead of
#    being re-described and re-interpreted
codex-imagegen "A shield with a checkmark inside it. Match the reference image's style, \
palette, stroke weight, background and margins exactly. $STYLE" \
  assets/icon-shield.png --ref assets/icon-rocket.png --size 1024x1024

# 3. sibling — same idea, refed off the shield
#
#    The first attempt at this one came back wrong: gpt-image-2 inverted the palette and
#    filled the whole canvas with terracotta, leaving the gear as a nearly invisible
#    outline. The exit code was 0 and the PNG was valid — only opening it caught the
#    problem, which is exactly why the skills make Claude look at the image before
#    reporting success. The re-roll below states the background explicitly.
codex-imagegen "A six-tooth settings gear with a circular hollow center, drawn as a small \
centered glyph. The background must stay warm off-white #FAF9F5 across the whole canvas — \
do NOT fill the canvas with terracotta. The gear itself is terracotta #D97757 with a \
darker #8C4A32 2px outline. Match the reference image's style, stroke weight, glyph scale \
and generous margins exactly: a small glyph on a large pale background. Flat vector, no \
gradients, no shadows, no text." \
  assets/icon-gear.png --ref assets/icon-shield.png --size 1024x1024

# 4. the GitHub social preview — 1280x640 is GitHub's recommended size, and it happens
#    to satisfy gpt-image-2's constraints (both edges multiples of 16, ratio <= 3:1)
codex-imagegen "Wide banner illustration, no text of any kind. Two rounded squares side \
by side connected by a thick horizontal bridge in the middle: the left square holds a \
terminal prompt chevron glyph, the right square holds a picture glyph. Flat vector, warm \
off-white #FAF9F5 background, terracotta #D97757 shapes with darker #8C4A32 2px outlines, \
a muted slate #3D3D3A accent, no gradients, no shadows, no lettering, wide empty margins, \
centered composition." assets/social-preview.png --size 1280x640
```

## The demo GIF

`demo.gif` is a real recording of `codex-imagegen`, not a mockup. Re-record it with
[VHS](https://github.com/charmbracelet/vhs):

```bash
brew install vhs              # pulls in ttyd and ffmpeg, which it needs
vhs assets/demo.tape          # writes assets/demo-raw.gif (real time, ~2 min)
```

VHS drives a real terminal through `ttyd` on a local port and screenshots it with headless
Chrome, so it will fail with `could not open ttyd: ERR_CONNECTION_REFUSED` under any
sandbox that blocks loopback binding. Run it in a normal shell.

The raw recording is 137 seconds, and about 115 of those are a frozen screen while
gpt-image-2 works. Uniformly speeding that up gives you a GIF that is still mostly a still
image and blurs past the payoff, so the committed `demo.gif` instead keeps the two ends and
cuts the wait: the typing runs at 1.6×, the dead stretch is dropped, and the result — the
printed path and `file` confirming a real 1024×1024 PNG — plays at true speed.

```bash
ffmpeg -i assets/demo-raw.gif -filter_complex "\
  [0:v]trim=0:15,setpts=(PTS-STARTPTS)/1.6[a];\
  [0:v]trim=128:137.3,setpts=PTS-STARTPTS[c];\
  [a][c]concat=n=2:v=1[v];\
  [v]fps=13,scale=1000:-1:flags=lanczos,split[x][y];\
  [x]palettegen=stats_mode=diff[p];[y][p]paletteuse=dither=bayer" \
  -loop 0 assets/demo.gif
```

Adjust the two `trim` windows if your recording runs longer or shorter than 137s.
**The cut is the wait, not the work** — nothing in the GIF is staged or re-enacted.

## Notes

- `icon-rocket.png` came back at 1254×1254 rather than the requested 1024×1024 —
  gpt-image-2 treats size as a strong hint, not a contract. Resample locally if you need
  an exact edge length; don't regenerate for it.
- The social preview is **not** set by committing this file. Upload it manually at
  **Settings → General → Social preview** — GitHub has no API for it.
